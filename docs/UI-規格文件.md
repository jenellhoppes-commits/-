# 娛樂資訊網站 UI／前端規格

版本：1.0  
更新日期：2026-09-29  
正式原型：https://jenellhoppes-commits.github.io/-/

## 1. 專案定位

本網站為娛樂平台資訊與遊戲攻略型部落格原型。內容以娛樂城推薦、平台評價、遊戲攻略、USDT 入門與玩家討論為主，整體視覺沿用資訊型網站的清楚排版與內容密度，再以藍色品牌系統建立識別。

核心原則：

- 資訊優先：標題、摘要、比較欄位與行動按鈕需容易掃讀。
- 藍色主視覺：白色與冰藍底、深藍文字、亮藍操作元件、青色輔助亮點。
- 內容與品牌分離：遊戲圖片可保留原始色彩，但 UI 元件不使用橘色作為主色。
- 響應式優先：桌機顯示完整導覽；平板與手機改用漢堡選單。
- 負責任資訊：所有涉及娛樂平台的頁面需保留年齡、法規與理性娛樂提醒。

## 3. 全站導覽規格

### 桌機版

- Header 固定於畫面頂部，滾動時保持可見。
- 高度：70 px。
- 最大內容寬度：1220 px。
- 左側為 46 × 46 px 的無文字品牌圖標。
- 中間導覽：首頁、娛樂城推薦、娛樂城攻略、遊戲攻略、關於我們。
- 右側操作：登入、註冊。
- 桌機版不顯示漢堡選單。
- 目前頁面與 Hover 狀態使用冰藍膠囊底與主藍文字。

### 平板與手機版

- 1040 px 以下隱藏完整導覽，顯示漢堡選單。
- 右側依序為登入、註冊、漢堡選單。
- 漢堡選單開啟後由右側滑出內容導覽抽屜，背景加深色遮罩。
- 720 px 以下 Header 高度為 64 px，Logo 顯示尺寸為 42 × 42 px。
- 430 px 以下縮減左右留白與按鈕水平內距。

### 帳戶按鈕

- 登入：白底、1 px 藍框、藍字。
- 註冊：主藍底、白字。
- 圓角：10 px。
- 最小高度：38 px；手機版 36 px。
- 目前僅為 UI 原型，尚未串接會員系統。

## 7. 核心元件規格

### 品牌圖標

- 檔案：`public/assets/brand-symbol.png`。
- 原始格式：透明背景 PNG、正方形構圖、藍青配色、無文字。
- Header：46 × 46 px；手機 42 × 42 px。
- Footer：68 × 68 px。
- 關於我們 Hero：最大寬度 370 px。
- 不得加上舊品牌名稱、3A 字樣或其他文字鎖定。

### 按鈕

- 一般高度：至少 50 px。
- 水平內距：24 px。
- 邊框：2 px。
- Primary：主藍底、白字。
- Secondary：白底、主藍框、深藍字。
- Dark：深色資訊卡使用深藍黑底與白字。
- Hover：向上位移 2 px，主按鈕加深。
- Active：縮放至 98%。
- Focus：顯示明確藍色外框。

### Eyebrow 標籤

- 冰藍背景、深藍文字。
- 最小高度：34 px。
- 內距：7 × 14 px。
- 字級：13 px，字重 800。
- 使用於 Hero、Section Header、文章分類與 CTA 標示。

### 資訊卡

- 白底、1 px 淺藍灰邊框。
- 圓角：18–24 px。
- 頂部藍色 4–5 px 強調線可用於主題卡與評選卡。
- 卡片內距：18–28 px。
- Hover 僅使用輕微位移與陰影，不做劇烈動畫。

### FAQ

- 預設第一題展開。
- 每題最小高度：76 px。
- 點擊後切換「展開／收合」文字與 `aria-expanded`。
- 同一時間允許一題展開；再次點擊可全部收合。

### 文章卡

- 圖片比例：4:3。
- 顯示分類標籤、日期、瀏覽數、標題、摘要與「閱讀文章」。
- 圖片 Hover 放大至 1.035 倍。
- 桌機 4 欄、平板 3 欄、手機 1 欄。

## 9. Footer 規格

- 深色背景 `#14191D`。
- 桌機為四欄：品牌說明、探索、關於本站、聯絡我們。
- 平板改為三欄，聯絡資訊獨占下一列。
- 手機改為單欄。
- 必須包含 `18+` 年齡提示與「僅提供資訊、不經營博弈、不代收下注」聲明。
- 分區標題使用青藍色 `#62CCE8`。

## 10. 動態與互動

- 頁內錨點使用平滑滾動。
- SPA 換頁後回到頁面頂部。
- 按鈕 Hover 動畫：180–250 ms。
- 遊戲卡 Hover：上移 4 px。
- 行動版抽屜使用遮罩並可由「關閉」或點擊遮罩退出。
- 登入與註冊目前無實際流程；正式開發時需新增表單、驗證、錯誤訊息與會員狀態。

## 11. 無障礙與內容規範

- 所有可操作元件必須可使用鍵盤操作。
- Focus 狀態不可移除。
- 裝飾圖片使用空 `alt`；內容圖片使用描述性替代文字。
- FAQ 必須保留 `aria-expanded`。
- 導覽與麵包屑需有可辨識的 `aria-label`。
- 文字與背景對比至少符合 WCAG AA。
- 手機觸控目標建議至少 44 × 44 px。
- 不使用保證獲利、保證出金或鼓勵追損的文案。
- 所有平台條件與活動資訊應標示以官方最新公告為準。

## 12. 素材與技術規格

- 前端：React 19、Vite 6。
- 部署：GitHub Pages。
- 路由：前端 History API；部署產生 `404.html` 作為 SPA fallback。
- 圖片統一放置於 `public/assets/`，正式頁面不使用外部熱連結。
- 字型檔：`sf-pro-display_regular.woff2`。
- 正式建置指令：`npm run build:pages`。
- 測試指令：`npm run test:sites`。
